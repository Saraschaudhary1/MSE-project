Asha Kiran Foundation – NGO Website

A clean, responsive, and modern web application built for the Asha Kiran Foundation—a non-profit organization dedicated to empowering underprivileged communities through education, healthcare, food drives, and environmental initiatives.

🚀 Features

Responsive Design: Fully optimized for desktop, tablet, and mobile screens.
Structured Sections: Includes Hero, About Us, Core Causes, Step-by-Step Initiative Guide, Impact Statistics , Volunteer Sign-up Form, Community Testimonials, and Contact Information.
Interactive Elements: Sticky navigation bar, styled donation amount cards, and custom form inputs.

🛠️ Built With

HTML5: Semantic document structure.
CSS3: Custom styling, Flexbox layout, and media queries for responsiveness.
